# Change ledger — CH-nn

Bridge between the immutable verbatim shards and decided requirement changes.
Every answer that CHANGES or ADDS a requirement gets a row; status `decided` →
`reflected` once shards/tickets are updated. The Impact column is never empty:
business (BA) · technical (SA) · schedule (PM).

| CH | Source | Requirement delta | Impact | Status |
