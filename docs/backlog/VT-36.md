# VT-36: the fence charges a README typo what it charges a payment rewrite — measure the risk, stop the review theatre
- status: In Review
- labels: review, cost, doctrine
- estimate: 1d
- type: Task

**30-second summary:** every change, however textual, needed two fresh reviewer agents with three
"tried to break" bullets each. On a one-line copy change there is nothing to try, so the bullets
get invented — cards written to satisfy a counter stop being evidence. `change_class.py` now reads
the DIFF and returns `docs` / `surface` / `logic` / `high-stakes`; `review_check` picks the review
shape from that class. The agent never declares it, and every doubt resolves upward.

## Why
Measured on this repo, not argued: the smallest change of the week (VT-29 deleted one `--depth=1`
flag) cost ≈60k tokens and 9 changed files, 5 of them procedure. 12 of the last 40 commits touch
no executable file at all, and each of them paid for two reviewer agents — ≈17k tokens of
mandatory doctrine each, per VT-33's measurement. Spec: `core/doctrine/red-flags.md` row 2 and
`core/doctrine/review-standard.md`; the counter-argument is that row 2 exists because "too small
to review" preceded real outages, which is why the class is machine-measured and fails closed. no UI.

## Acceptance criteria
- Given a diff where no executable file moved / When review_check runs / Then it passes with no reviewer card and prints the class and the reason; the gate, the evidence pack and the ledger row are unaffected.
- Given a diff where only string bodies, comments or JSX text moved, under `review.surface_max_lines` / When review_check runs / Then exactly one card is required and one "tried to break" bullet suffices — traces still mandatory.
- Given any other diff / When review_check runs / Then the requirement is exactly what it was before this ticket (`review.reviewers` cards, three bullets, plus the architecture card on high-stakes).
- Given `review.proportional: false` / When review_check runs on a docs-only diff / Then the uniform fence is back — one config line reverses everything.
- Given an added or deleted code file, a rename with a code file on either side, a config or data file, a template literal, an unparsable file, or more changed lines than the cap / When classified / Then the class is `logic`.

## Out of scope
Shrinking the evidence pack itself (tasksheet/proof/report) for light classes — that is evd_check's policy and its own ticket; changing what `/qa` verifies; any change to the escape hatch or its log.
