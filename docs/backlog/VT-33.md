# VT-33: Measure the doctrine a lane actually loads — the "31 competencies bloat the context" claim had no number
- status: In Review
- labels: doctrine, measurement, gate
- estimate: 0.5d
- type: Task

**30-second summary:** the benchmark critique asserts that vteam's 31 competencies bloat the
agent's context. Nothing measured it. `context_budget.py` reads each lane's rendered skill,
resolves the files it tells the agent to read before any ticket work, and prints bytes and
≈tokens per file, mandatory and on demand apart. Measured on this repo: the heaviest lane (qa)
loads ≈17.5k tokens before a ticket, of which the skill itself is half; a lane loads four or
five competencies by default, not 31. The tool runs as an advisory gate step.

## Why
A claim about cost that nobody can check is argued forever; a table settles it and shows where
the weight really is (the lane skills, 17–36 KB each — not the competency files). Spec:
docs/BENCHMARK.md ("How the two runs went"), core/workflows/dev.md ("Who is working", "Load the
competencies this ticket needs"). no UI.

## Acceptance criteria
- Given `--lane dev` / When run in this repo / Then the mandatory list is the skill, the identity, the role playbook, the competency INDEX and every INDEX row marked `always`, with bytes and ≈tokens (bytes/4, stated) and a total; files the skill names conditionally are listed apart as on demand.
- Given a referenced file that does not exist / When measured / Then it is ignored (a file that is not there cannot be loaded); a file named twice counts once.
- Given `team.context_budget_tokens` (default 40000) / When a lane's mandatory total exceeds it / Then `⚠️  over budget` is printed and the exit code is still 0 — a measurement, not a fence.
- Given a fresh install / When the gate runs / Then the `context-budget` advisory step runs and the gate stays GREEN; the step is in gate.py's bookkeeping set so it never upgrades a WEAK banner.
- Given `--selftest` / When a code-only mutation removes the exists guard, the budget comparison or the `always` rows / Then it is RED each time.

Budget: 40 000 tokens (default). No lane is over it. What the numbers say: the competencies are
not the weight — a lane loads 4–5 of the 31, ≈4–5k tokens; the lane skill itself is 35 KB for
dev and 34 KB for qa and is the single largest item in every lane. If context is to be cut,
the skills are where to cut, and this tool is how to prove the cut happened.
